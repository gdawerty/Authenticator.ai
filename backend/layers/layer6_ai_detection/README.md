# Layer 6: AI Detection

This layer detects AI-generated content in documents.

## Purpose
- Detect AI-generated text
- Identify synthetic content
- Calculate AI generation probability
- Support multiple detection methods

## Components
- Fast-DetectGPT implementation
- Multiple detection algorithms (entropy, likelihood, rank, etc.)
- AI content scoring
- Model-based detection utilities

## Integration
- Analyzes documents for AI-generated content
- Feeds into final authenticity prediction
- Works with other layers for comprehensive analysis

## Detection Methods
- Entropy-based detection
- Likelihood analysis
- Rank-based detection
- Log-rank analysis
- Sampling discrepancy analysis
